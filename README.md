# Polite Scraper Pipeline

## Target Classification
- **Target Site**: Books to Scrape (`https://books.toscrape.com/`)
- **Purpose**: Practice sandbox built specifically for web scraping education and testing.
- **Scope**: First 3 catalogue pages (~60 books total).
- **Data Collected**: Book titles, product URLs, prices, stock availability, star ratings, descriptions, source page, and timestamp.
- **Robots.txt Result**: `https://books.toscrape.com/robots.txt` returned a status 404 / no specific disallow rules found for catalogue pages.
- **Ethical Commitment**: I will not reuse this code on another site without checking its rules and terms first.
